# Noam's Jungle 🌴

Client Side – Homework 3

An interactive jungle website built with HTML, CSS and JavaScript.
Click an animal (or press its key) to hear its sound, while jungle music plays in the background.

**Live site:** https://USERNAME.github.io/REPO-NAME/

## Keyboard keys

| Key | Animal |
|-----|--------|
| L | Lion |
| E | Elephant |
| M | Monkey |
| G | Giraffe |
| B | Bear |
| D | Dog |
| O | Cow |
| C | Chipmunk |

## Features

- 8 animals with images and sounds
- Background music with play/pause and volume control
- Search, random animal button and play counters
- Responsive layout (CSS Grid, Flexbox, media queries)
- New element: `element.animate()` (Web Animations API) – explained in `script.js`
